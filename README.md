Music Disk Builder  
==================  
  
Based on Music Disks from Phantasy Star Online.  
Generates deterministic metadata for given MP3s.  

! WARNING ! this will destroy any meaningful metadata.
  

Requirements  
------------  
Windows 10/11  
  

For users  
---------  
Download the latest MusicDiskBuilder.exe from Releases and run it.  
  

For development  
---------------  
Install dependencies:  
    `python -m pip install -r requirements.txt`

Run:  
    `python run_gui.py`
